Ramses est une application qui vous accompagne de l'importation de vos données jusqu'à la rédaction de votre rapport d'analyse. Conçu pour les débutants, les étudiants et les professionnels de terrain.

À quoi ça sert ?

Vous avez un fichier Excel, CSV ou SPSS rempli de données. Vous voulez en tirer des conclusions : moyennes, graphiques, tests statistiques, tableau de synthèse.

Ramses vous guide pas à pas. Vous cliquez, l'application calcule, et vous obtenez un résultat clair — sans jamais avoir à apprendre la programmation.

Et si vous voulez comprendre ce qui se passe « sous le capot », tout le code R utilisé est automatiquement conservé pour vous.

En une phrase

Vous faites de la statistique. Ramses se charge de la technique.

Votre parcours en 5 étapes

Chaque analyse suit naturellement la même logique. Ramses est structuré autour de ces cinq moments clés.

1 Importez

Chargez vos fichiers .csv, .xlsx, .sav ou .dta. Ramses détecte le format et vous laisse ajuster les options.

2 Préparez

Vérifiez la qualité de vos données : valeurs manquantes, doublons, valeurs aberrantes. Renommez, recodez, filtrez — tout est guidé.

3 Explorez

Décrivez vos variables (moyennes, médianes, effectifs, pourcentages) et croisez-les pour repérer les tendances.

4 Analysez

Choisissez un test statistique (t, ANOVA, Chi-deux, corrélation, régression…) à partir d'une simple question.

5 Documentez

Exportez votre rapport en HTML, votre code en R ou en R Markdown. Vos analyses sont reproductibles.

+ Apprenez

À chaque clic, le code R correspondant s'affiche dans le journal. Vous apprenez sans vous en rendre compte.

Quel outil pour quelle question ?

Pas besoin de connaître le nom des tests. Cherchez simplement votre question dans la colonne de gauche.

Votre question Ce que Ramses utilise
Mes données suivent-elles une loi normale ? Test de normalité
Une moyenne est-elle différente d'une valeur de référence ? Test t à 1 échantillon
Deux groupes ont-ils des moyennes différentes ? Test t indépendant (ou Mann-Whitney)
Avant / après une intervention : y a-t-il un changement ? Test t apparié (ou Wilcoxon)
Trois groupes ou plus sont-ils différents ? ANOVA (ou Kruskal-Wallis)
Deux variables qualitatives sont-elles liées ? Test du Chi-deux (ou Fisher)
Deux proportions sont-elles différentes ? Test de proportions
Deux variables quantitatives évoluent-elles ensemble ? Corrélation Pearson / Spearman
Je veux prédire une valeur numérique. Régression linéaire
Je veux prédire une catégorie (oui/non). Régression logistique
⚠️ À retenir

Un test statistique ne se choisit jamais au hasard. Il dépend de votre question, du type de vos variables et de votre plan d'étude. Ramses vous guide, mais reste à votre service.

Ce que Ramses ne fera jamais à votre place

Ramses automatise les calculs. Mais il ne peut pas :

  • Décider si votre question de recherche est pertinente.
  • Vérifier si vos variables mesurent vraiment ce que vous croyez.
  • Remplacer votre jugement scientifique sur les résultats.
  • Corriger un mauvais plan d'expérience.

Vous restez aux commandes. Ramses s'occupe de la technique. Vous vous occupez du sens.
