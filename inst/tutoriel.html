Bien démarrer avec Ramses

En 5 minutes, faites votre première analyse. Le principe : comprendre ce que vous faites, pas cliquer partout.

La règle d'or

Toujours dans le même ordre

1. Préparer → 2. Décrire → 3. Visualiser → 4. Analyser → 5. Documenter.

Ce parcours est valable pour toute analyse de données. Ramses vous fournit les outils. C'est vous qui reliez chaque étape à votre question.

Étape 1 — Ouvrir Ramses

R
library(Ramses)
run_app()

Ramses démarre avec un jeu de données d'exemple (iris). Vous pouvez vous entraîner immédiatement.

Étape 2 — Comprendre votre jeu de données

Avant tout calcul, posez-vous ces 5 questions simples :

  • Combien ai-je d'observations (lignes) ?
  • Combien ai-je de variables (colonnes) ?
  • Quelles variables sont numériques (quantitatives) ?
  • Quelles variables sont catégorielles (qualitatives) ?
  • Y a-t-il des valeurs manquantes ou aberrantes ?

Dans Préparation des données → Explorer, Ramses répond automatiquement à ces questions.

Étape 3 — Importer vos propres données

Cliquez sur Importer et choisissez votre fichier.

FormatCe que vous pouvez ajuster
.csv, .txt, .tsvSéparateur, décimales, présence d'en-tête
.xlsx, .xlsChoix de la feuille, noms de colonnes
.sav (SPSS)Conversion des labels en facteurs
.dta (Stata)Conversion des labels en facteurs
.rds, .RDataLecture directe d'un objet R

Après le chargement, Ramses remplace le jeu actif et ajoute l'opération dans le journal.

Étape 4 — Nettoyer les données

L'onglet Préparation vous permet de :

⚙️ Modifier

Renommer, supprimer, réorganiser, recoder, créer une variable calculée.

🧹 Nettoyer

Gérer les valeurs manquantes, doublons, espaces et casse du texte.

🔍 Filtrer

Sélectionner certaines lignes, trier, ne garder que les variables utiles.

📋 Diagnostiquer

Valeurs aberrantes, résumés rapides, qualité du jeu de données.

⚠️ Attention aux transformations

Ne supprimez pas une valeur uniquement parce qu'elle vous gêne. Une donnée inhabituelle peut être une vraie observation. Comprenez sa cause avant de la modifier.

Étape 5 — Décrire vos données

Rendez-vous dans Statistiques descriptives et choisissez selon vos variables :

  • Variable quantitative : moyenne, médiane, écart-type, minimum, maximum, quartiles.
  • Variable qualitative : effectifs, pourcentages, diagrammes en barres.
  • Deux variables qualitatives : tableau croisé avec pourcentages ligne/colonne/total.
  • Deux variables quantitatives : matrice de corrélation (Pearson ou Spearman).

Étape 6 — Construire un graphique

Ouvrez Visualisation. Choisissez le type de graphique, puis associez vos variables aux axes.

ÉlémentQuestion simple
XQuelle variable sur l'axe horizontal ?
YQuelle variable sur l'axe vertical ?
CouleurQuelle variable distingue les groupes ?
FacetteFaut-il un sous-graphique par groupe ?

Types disponibles : nuage de points, barres, camembert, boxplot, violon, histogramme, ligne, densité, heatmap.

Étape 7 — Choisir un test

Ne cherchez pas le nom du test. Cherchez votre question.

Votre questionCe que Ramses utilise
Un groupe vs une valeur de référenceTest t à 1 échantillon
Deux groupes indépendantsTest t indépendant
Avant / après (mêmes individus)Test t apparié
Trois groupes ou plusANOVA
Deux variables qualitativesChi-deux
Deux variables quantitativesCorrélation
💡 Avant de lancer

Vérifiez le type des variables, le nombre de groupes, l'indépendance/appariement et les hypothèses du test. Ramses vous guide.

Étape 8 — Lire le résultat

Ne regardez pas uniquement la p-value. Regardez aussi :

  • La statistique du test.
  • La différence observée (effet).
  • L'intervalle de confiance.
  • La taille d'effet.
  • Le contexte et l'importance pratique.

Une différence peut être statistiquement significative sans être importante en pratique. Et l'inverse aussi.

Étape 9 — Documenter l'analyse

Chaque action est consignée dans le Journal Rmd. Vous pouvez :

  • Ajouter des notes personnelles.
  • Copier le script R.
  • Exporter en .R, .Rmd ou rapport .html.

Checklist avant de présenter vos résultats

  • ☐ Données vérifiées (types, valeurs manquantes, aberrantes)
  • ☐ Variables correctement codées
  • ☐ Test cohérent avec le plan d'étude
  • ☐ Hypothèses du test vérifiées
  • ☐ Résultat statistique correctement interprété
  • ☐ Importance pratique discutée
  • ☐ Code et rapport conservés
