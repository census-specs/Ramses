Vérifier les conditions d'un test

Avant de conclure, s'assurer que la méthode est bien appliquée

1. Le test t ne fonctionne pas toujours !

La situation typique

« J'ai lancé un test t sur mes données. Il me dit p = 0,04, donc significatif. Mais mon collègue dit que ce n'est pas valable. Pourquoi ? »

Dans le module 08, nous avons vu qu'un test t de Student compare deux moyennes. Mais ce test repose sur des hypothèses mathématiques précises. Si ces hypothèses ne sont pas raisonnablement respectées, le résultat du test n'est pas fiable — même si R affiche une belle p-value.

Une règle à retenir

« Aucun test n'est valable sans vérifier ses conditions d'application. »

2. Les 3 conditions à vérifier

Pour le test t de Student (indépendant ou apparié), trois conditions doivent être vérifiées :

1
Indépendance des observations
Chaque observation doit être indépendante des autres. Deux mesures sur la même parcelle ne sont pas indépendantes. Ce point relève du plan expérimental, pas d'un test.
2
Normalité des données (ou du moins leur proximité)
Les résidus (ou les données elles-mêmes) doivent suivre approximativement une loi normale en forme de cloche. C'est surtout important pour de petits échantillons (n < 30).
3
Égalité des variances (uniquement pour 2 groupes indépendants)
Les deux groupes comparés doivent avoir des variances à peu près égales. On parle d'homoscédasticité.
Bonne nouvelle

Le test t est robuste : il tolère de petits écarts sur la normalité et les variances, à condition que les groupes soient suffisamment grands (n ≥ 30 par groupe). Pour de petits échantillons, il faut être plus prudent.

3. Vérifier la normalité

Deux outils complémentaires : visuel (graphique) et formel (test statistique).

Outil 1 — Le QQ-plot (visuel)

Un QQ-plot compare la distribution de vos données à une distribution normale théorique. Si les points s'alignent sur la diagonale, la normalité est plausible. 

# QQ-plot pour vérifier la normalité
qqnorm(donnees$rendement)
qqline(donnees$rendement, col = "red")
Deux QQ-plots comparés
Alignement sur la droite = normalité plausible
Diagnostic visuel

Outil 2 — Le test de Shapiro-Wilk (formel)

Le test de Shapiro-Wilk vérifie formellement si la distribution s'écarte significativement de la normalité : 

# Test de normalité de Shapiro-Wilk
shapiro.test(donnees$rendement)

# Sortie :
#   Shapiro-Wilk normality test
#   data:  donnees$rendement
#   W = 0.96, p-value = 0.78
Comment lire ce test ?

• $p > 0{,}05$ : on ne rejette pas la normalité → on peut utiliser un test paramétrique comme le test t.
• $p < 0{,}05$ : la normalité est rejetée → envisager une alternative non paramétrique.

Attention : c'est l'inverse de la logique habituelle ! Ici, un p élevé est rassurant.

4. Vérifier l'égalité des variances

Pour deux groupes indépendants, il faut que les variances soient à peu près égales (homoscédasticité). Deux tests classiques :

  • Test de Bartlett : suppose la normalité, très sensible aux écarts.
  • Test de Levene : plus robuste, moins sensible aux distributions non normales. Recommandé par défaut.
# Test de Levene (plus robuste)
library(car)
leveneTest(rendement ~ variete, data = donnees)

# Test de Bartlett (si normalité confirmée)
bartlett.test(rendement ~ variete, data = donnees)
Lecture du test

• $p > 0{,}05$ : variances homogènes → test t standard est OK.
• $p < 0{,}05$ : variances inégales → utiliser la variante var.equal = FALSE du test t (test de Welch), plus sûre. 

# Test t de Welch (ne suppose pas l'égalité des variances)
t.test(rendement ~ variete, data = donnees, var.equal = FALSE)

6. Que faire si les conditions ne sont pas respectées ?

Pas de panique : il existe des alternatives robustes aux tests t, appelées tests non paramétriques. Elles ne supposent aucune forme particulière de distribution.

Situation Test paramétrique Alternative non paramétrique
1 groupe vs référence t.test(x, mu = ...) wilcox.test(x, mu = ...)
2 groupes indépendants t.test(y ~ g) wilcox.test(y ~ g) (Mann-Whitney)
2 groupes appariés t.test(x, y, paired = TRUE) wilcox.test(x, y, paired = TRUE)
3 groupes ou plus ANOVA aov(y ~ g) kruskal.test(y ~ g) (Kruskal-Wallis)
Quand préférer un test non paramétrique ?

• Distribution clairement non normale ET petit échantillon (n < 20 par groupe).
• Présence de valeurs aberrantes qui ne sont pas des erreurs.
• Données ordinales (notes, échelles de satisfaction).
• Variances très inégales entre groupes.

7. Et dans Ramses ?

Ramses guide automatiquement la vérification des conditions et propose le test approprié :

1. Ouvrir le diagnostic automatique
Dans l'onglet « Tests Statistiques », activez l'option « Vérification automatique des conditions ».
2. Consulter le tableau de bord
Ramses affiche automatiquement :
• QQ-plot de chaque groupe ;
• Résultat du test de Shapiro-Wilk ;
• Résultat du test de Levene ;
• Une recommandation : « Conditions respectées → test t » ou « Normalité rejetée → Mann-Whitney ».
3. Suivre la recommandation ou forcer
Vous pouvez accepter la suggestion de Ramses ou forcer manuellement un test (avec un avertissement de sa part). Toutes les décisions sont journalisées.

8. Petit défi interactif

À vous de jouer !

Vous avez lancé un test de Shapiro-Wilk sur vos données et vous obtenez p = 0,003. Quelle est la bonne interprétation ?

Ce qu'il faut retenir

• Tout test paramétrique repose sur des conditions d'application.
• Les 3 conditions du test t : indépendance, normalité, égalité des variances.
• Le test de Shapiro-Wilk vérifie la normalité. Un p élevé est rassurant.
• Le test de Levene vérifie l'égalité des variances. Un p élevé est rassurant.
• Si les conditions ne sont pas respectées : alternative non paramétrique (Mann-Whitney, Wilcoxon, Kruskal-Wallis).
• Ramses automatise ce diagnostic et recommande le test adapté.

« Un résultat n'est valable que si les conditions du test sont vérifiées. »
