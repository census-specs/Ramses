Comprendre mes variables : quelles informations contient mon fichier ?

Apprendre à reconnaître simplement les différents types de données et savoir quoi en faire

Dans le module précédent, nous avons découvert notre fichier agricole. Nous avons vu que chaque ligne représente une observation (une parcelle) et que chaque colonne représente une information.

Mais regardons maintenant attentivement les noms de nos colonnes :

Village Superficie Rendement

Peut-on vraiment traiter ces trois informations de la même manière ?

Posons-nous une question toute simple :

Peut-on calculer la moyenne du village ?

❌ Non.

Pourquoi ? Parce que l'opération Bonabéri + Bépanda n'a strictement aucun sens mathématique.
En revanche, additionner 1,2 ha + 0,8 ha pour obtenir 2,0 hectares a un sens physique immédiat et concret.

C'est exactement cette différence fondamentale que nous allons explorer ensemble.

2. La question clé : quelles colonnes peut-on additionner ou moyenner ?

Regardons le contenu de chaque colonne une par une :

Colonne Village

Contenu : Bonabéri, Bépanda

Ce sont des noms, des étiquettes, des catégories. On ne peut pas les additionner, mais on peut les compter.

Colonnes Superficie & Rendement

Contenu : 0,7 ; 1,2 ; 2,8 ; 3,4...

Ce sont de véritables nombres. On peut les additionner, en calculer la moyenne, trouver le minimum ou le maximum.

Nous venons de découvrir sans le savoir les deux grandes familles de données en statistique.

3. Première famille : la variable qualitative

Définition simple

Une variable qualitative décrit une catégorie, un groupe ou une caractéristique.

En agriculture et dans la vie courante, nous utilisons des variables qualitatives tous les jours :

Exemple de variable Catégories possibles (modalités)
Village Bonabéri, Bépanda, Dibombari...
Sexe de l'agriculteur Femme, Homme
Variété de maïs CMS 8704, KASAI, Expérimentale A...
Type de sol Argileux, Sableux, Limoneux
Utilisation d'engrais Oui, Non

Posons-nous deux questions très simples :

  • Peut-on calculer la moyenne du village ? → ❌ Non, cela n'a aucun sens.
  • Peut-on compter combien de parcelles sont à Bonabéri ? → ✅ Oui, absolument !
Règle d'or

Avec une variable qualitative, on ne calcule pas de moyenne : on compte des effectifs (le nombre de fois où chaque catégorie apparaît) et on calcule des pourcentages (la part de chaque catégorie).

4. Deuxième famille : la variable quantitative

Définition simple

Une variable quantitative est une information numérique sur laquelle on peut effectuer des calculs mathématiques (somme, moyenne, écarts).

Quelques exemples très fréquents :

  • Le rendement : 2,1 ; 2,8 ; 3,4 t/ha.
  • La superficie : 0,7 ; 1,2 ; 2,0 hectares.
  • La dose d'engrais apportée : 50, 100, 150 kg/ha.
  • Le nombre de sacs récoltés : 14, 22, 35 sacs.
  • L'âge de l'agriculteur : 32, 45, 58 ans.

Posons la question :

Peut-on calculer le rendement moyen ? → ✅ Oui !

Demandons à R de faire ce calcul à partir de notre colonne rendement :

# Création de notre tableau dans R
donnees <- data.frame(
  parcelle   = c("P01","P02","P03","P04","P05","P06","P07","P08","P09","P10"),
  village    = c("Bonabéri","Bonabéri","Bonabéri","Bonabéri","Bonabéri","Bépanda","Bépanda","Bépanda","Bépanda","Bépanda"),
  superficie = c(1.2, 0.8, 1.5, 1.0, 2.0, 0.7, 1.1, 1.4, 0.9, 1.8),
  rendement  = c(2.8, 2.4, 3.1, 2.7, 3.4, 2.1, 2.5, 2.9, 2.3, 3.0)
)

# Calcul de la moyenne de la colonne rendement
mean(donnees$rendement)
[1] 2.72

Dans ce code, le symbole dollar (donnees$rendement) dit simplement à R : « Va dans le tableau appelé donnees et prends uniquement la colonne rendement ». R calcule alors la moyenne arithmétique : 2,72 t/ha.

5. Faisons une petite expérience

Pour être certain d'avoir bien saisi la nuance, testez-vous avec ce petit récapitulatif :

Variable Type d'information Peut-on calculer la moyenne ? Opération recommandée
Village Qualitative (catégorie) ❌ Non Compter les effectifs et pourcentages
Superficie (ha) Quantitative (mesure) ✅ Oui Moyenne, minimum, maximum
Rendement (t/ha) Quantitative (mesure) ✅ Oui Moyenne, dispersion
Variété de maïs Qualitative (nom) ❌ Non Nombre de parcelles par variété
Âge de l'exploitant Quantitative (nombre d'années) ✅ Oui Âge moyen de l'échantillon

Voyez comme c'est simple : inutile d'apprendre des formules par cœur, il suffit de se demander : « Est-ce que cette information se mesure ou se classe ? »

6. Une subtilité importante : les chiffres qui ne sont pas des nombres !

Voici un piège très fréquent rencontré dans les fichiers de données :

Parfois, pour gagner du temps lors de la saisie, un enquêteur enregistre des codes numériques à la place de mots :

Code 1 = Homme
Code 2 = Femme

Si vous demandez la moyenne de cette colonne à un ordinateur, il répondra par exemple 1.5 sans hésiter !

Mais que signifie une moyenne de 1.5 pour le sexe d'une personne ? Absolument rien.

Le piège à éviter

Ce n'est pas parce qu'une colonne contient des chiffres qu'elle représente forcément une quantité !

Si le chiffre est un code (1 = Homme, 2 = Femme, ou un numéro d'identifiant), la variable reste qualitative.

8. Un vrai graphique pour notre variable qualitative

Dans le module 1, nous avions tracé un histogramme pour notre variable quantitative (le rendement).

Comment représenter maintenant notre variable qualitative : Combien de parcelles appartiennent à chaque village ?

Nous utilisons un diagramme en barres :

Diagramme en barres : répartition des parcelles par village
Variable qualitative : village (Effectifs totaux = 10)
Variable qualitative
Chaque barre montre le décompte exact : 5 parcelles à Bonabéri et 5 parcelles à Bépanda.

Voyons le code R pour obtenir ce comptage et ce graphique :

# 1. Compter les parcelles par village (table d'effectifs)
table(donnees$village)
Bépanda Bonabéri 5 5 
# 2. Tracer le diagramme en barres avec R
barplot(
  table(donnees$village),
  col = c("#2563EB", "#059669"),
  main = "Nombre de parcelles par village",
  ylab = "Nombre de parcelles",
  xlab = "Village"
)

La commande table(...) compte simplement combien de fois chaque village apparaît dans notre colonne. Puis barplot(...) prend ce comptage et le dessine en barres verticales.

9. Et avec Ramses ?

Dans Ramses, vous n'avez pas besoin d'écrire ces lignes de code. Ramses identifie lui-même les types de variables et vous guide :

Le repère visuel dans Ramses

Dans l'onglet « Jeu de données », regardez l'en-tête de votre tableau :
• Les variables qualitatives portent le badge [Aa] (texte / catégories).
• Les variables quantitatives portent le badge [#] (nombres / mesures).

Pour analyser votre variable qualitative village dans Ramses :

1. Observer le jeu de données
Dans l'onglet « Jeu de données », la colonne village porte l'indication [Aa] : Ramses sait déjà qu'il s'agit d'une variable qualitative.
2. Ouvrir le menu approprié
Dans la barre de navigation, cliquez sur « Statistiques Descriptives », puis sélectionnez « Variables Qualitatives ».
3. Sélectionner la variable
Dans le champ « Variable qualitative : », choisissez village.
4. Choisir les options et le graphique
Laissez cochés Effectifs (N) et Pourcentages (%), puis sélectionnez « Diagramme en barres ». Cliquez enfin sur le bouton « Calculer & Journaliser ».
5. Consulter les résultats
Ramses génère instantanément :
  • Le tableau d'effectifs : 5 à Bonabéri (50%) et 5 à Bépanda (50%) ;
  • Le diagramme interactif sous l'onglet « Diagramme de distribution » ;
  • Le code R reproductible complet.
Ce que vous savez maintenant

Vous avez franchi une étape essentielle :

  • Reconnaître une variable qualitative : des catégories que l'on ne moyenne pas (ex: village, variété), mais que l'on compte avec table().
  • Reconnaître une variable quantitative : des valeurs numériques qui se mesurent et se moyennent (ex: rendement, superficie) avec mean().
  • Déjouer les pièges : savoir que des chiffres peuvent parfois être de simples codes (1 = Homme, 2 = Femme).
  • Choisir le bon graphique : utiliser un diagramme en barres pour des catégories, et un histogramme pour des quantités.
  • Utiliser Ramses : savoir naviguer entre « Variables Quantitatives » et « Variables Qualitatives » sans hésiter.
