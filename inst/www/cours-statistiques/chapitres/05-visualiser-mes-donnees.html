Visualiser mes données

Quel graphique choisir pour mieux comprendre mes données ?
La situation de l'agronome de terrain

« J'ai mes données sous forme de tableau, mais un tableau ne permet pas toujours de voir facilement ce qui se passe. Comment transformer mes données en graphiques utiles ? »

1. Commencer par le problème

Rappelons notre tableau habituel de 10 parcelles de maïs avec les trois variables suivies :

  • village : variable qualitative (catégories de lieu : Bonabéri ou Bépanda) ;
  • rendement : variable quantitative (en tonnes par hectare, t/ha) ;
  • superficie : variable quantitative (en hectares, ha).

La question fondamentale

« Quel graphique serait adapté à chacune de ces variables ? »

On ne choisit jamais un graphique au hasard ou pour faire « joli » : la forme du graphique dépend directement de la nature des variables (qualitative ou quantitative) et de la question que l'on se pose.

2. Variable qualitative : le diagramme en barres

Lorsque l'on étudie une seule variable qualitative comme le village, chaque ligne appartient à une catégorie distincte.

Règle d'or

« Pour comparer des catégories, le diagramme en barres est un bon choix. »

Le code R pour afficher ce diagramme :

barplot(
  table(donnees$village),
  main = "Nombre de parcelles par village",
  xlab = "Village",
  ylab = "Effectif"
)
Diagramme en barres (Barplot)
Variable qualitative : village (Effectif réel : 5 parcelles à Bépanda, 5 à Bonabéri)
Graphique réel R

3. Variable quantitative : l'histogramme

Lorsque l'on a une variable numérique continue comme le rendement, les nombres varient de manière continue.

Règle d'or

« L'histogramme permet de voir comment les valeurs quantitatives sont réparties. »

Le code R pour afficher l'histogramme :

hist(
  donnees$rendement,
  main = "Distribution des rendements",
  xlab = "Rendement",
  ylab = "Nombre de parcelles"
)
Histogramme (Distribution des rendements)
Variable quantitative continue : rendement (Classes régulières de 0.5 t/ha)
Graphique réel R

4. Comparer une variable quantitative entre groupes : le boxplot

Imaginons maintenant que nous voulons comparer les rendements selon le village (une quantitative rendement croisée avec une qualitative village).

Le boxplot (boîte à moustaches par groupe) permet de mettre côte à côte les distributions pour comparer immédiatement :

  • La médiane de chaque village (ligne centrale bleue) ;
  • L'étendue des récoltes de chaque terroir (la longueur de la boîte et des moustaches).

Le code R pour afficher cette comparaison :

boxplot(
  rendement ~ village,
  data = donnees,
  main = "Rendement selon le village",
  xlab = "Village",
  ylab = "Rendement"
)
Boîtes à moustaches comparatives (Boxplot par village)
Rendement (t/ha) comparé entre Bépanda (2.1 à 3.0, médiane 2.5) et Bonabéri (2.4 à 3.4, médiane 2.8)
Graphique réel R

5. Relation entre deux variables quantitatives : le nuage de points

Lorsque l'on a deux variables quantitatives continues (ici la superficie en ha et le rendement en t/ha), chaque parcelle est représentée par un point unique $(X, Y)$ sur le plan cartésien.

Règle d'or

« Le nuage de points permet d'observer visuellement la relation entre deux variables quantitatives. »

Le code R pour tracer ce nuage :

plot(
  donnees$superficie,
  donnees$rendement,
  main = "Superficie et rendement",
  xlab = "Superficie",
  ylab = "Rendement"
)
Nuage de points (Scatter plot)
Relation entre la superficie (X, 0.7 à 2.0 ha) et le rendement (Y, 2.1 à 3.4 t/ha)
Graphique réel R

6. Tableau récapitulatif

Voici la boussole simple à garder sous la main pour ne plus jamais hésiter :

Situation de vos données Graphique conseillé Fonction R
Une variable qualitative (ex: village) Diagramme en barres barplot()
Une variable quantitative (ex: rendement) Histogramme hist()

7. Maintenant, faisons la même chose dans Ramses

Dans l'application Ramses, vous disposez d'un studio graphique complet dédié à la visualisation interactive. Voici comment y accéder et tracer vos graphiques :

1. Ouvrir l'onglet « Visualisation »
Dans la barre de navigation supérieure principale, cliquez directement sur l'onglet « Visualisation » (icône de graphique en colonnes).
2. Choisir le type de graphique
Dans le menu déroulant « Type de graphique (Geom) : » du panneau latéral gauche, sélectionnez selon votre besoin :
• « Diagramme en barres (Barplot) » pour une variable qualitative ;
• « Histogramme de distribution » pour une variable quantitative seule ;
• « Boîte à moustaches (Boxplot) » pour comparer une quantitative selon un groupe ;
• « Nuage de points (Scatter plot) » pour croiser deux variables quantitatives.
3. Assigner les axes (X et Y)
Sous la section « Assignation des Axes & Dimensions » :
• Choisissez la variable d'abscisse dans « Axe X (Abscisse / Variable) : » ;
• Choisissez si besoin la variable d'ordonnée dans « Axe Y (Ordonnée - optionnel en 1D) : » ;
• Vous pouvez aussi associer une couleur dans « Couleur / Remplissage (Color/Fill) : » (ex: colorer les points par village).
4. Explorer et exporter
Le graphique Plotly se met à jour instantanément dans le panneau « Visualisation Interactive ».
• Cliquez sur le bouton « Code R » pour afficher le script ggplot2 reproductible ;
• Ou cliquez sur « Injecter dans le Journal R Markdown » pour archiver l'analyse.

8. Petit défi : Quel graphique choisir ?

Situation 1

Vous souhaitez représenter la répartition des producteurs par village. Quel graphique est le plus approprié ?

Situation 2

Vous analysez la distribution de l'âge des agriculteurs (une variable numérique continue allant de 22 à 68 ans). Quel graphique devez-vous choisir ?

Situation 3

Vous voulez observer si les parcelles ayant une plus grande superficie obtiennent un rendement plus élevé. Quel graphique convient le mieux ?

Ce qu'il faut retenir

• Catégories (qualitative) → barplot() (Diagramme en barres)
• Distribution (quantitative) → hist() (Histogramme)
• Comparaison entre groupes (quantitative ~ qualitative) → boxplot() (Boîte à moustaches)
• Relation bivariée (quantitative vs quantitative) → plot() (Nuage de points)

« Un bon graphique raconte une histoire claire dès les trois premières secondes. »
