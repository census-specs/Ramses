Comparer 3 groupes ou plus

Comment savoir si plusieurs groupes sont réellement différents ?

1. Partir d'un problème agricole

La question de terrain

« J'ai testé trois variétés de maïs. Les rendements moyens semblent différents. Comment savoir si ces différences sont suffisamment importantes pour conclure qu'il existe une différence entre les variétés ? »

Considérons un essai agronomique où le rendement en grains ($t/ha$) a été mesuré sur 5 parcelles indépendantes pour 3 variétés de maïs ($A$, $B$ et $C$) :

Variété Rendements observés ($t/ha$) Moyenne ($\bar{x}$)
Variété A 2.4, 2.5, 2.6, 2.5, 2.4 2,48 t/ha
Variété B 2.7, 2.8, 2.9, 2.8, 2.7 2,78 t/ha
Variété C 2.5, 2.6, 2.4, 2.5, 2.6 2,52 t/ha
Distribution réelle des rendements des trois variétés

2. Pourquoi ne pas faire plusieurs tests t ?

L'idée intuitive (mais risquée)

« Pourquoi ne pas comparer A avec B, puis A avec C, puis B avec C à l'aide de trois tests t de Student successifs ? »

L'intuition semble séduisante, mais elle comporte un piège statistique majeur :

L'inflation du risque d'erreur

Multiplier les tests augmente le risque d'obtenir au moins une différence significative simplement par hasard.

Si vous effectuez plusieurs comparaisons séparées, vous multipliez les chances de déclarer une fausse différence (une erreur de Type I). Plus le nombre de groupes augmente, plus ce risque d'erreur devient incontrôlable.

La solution : l'ANOVA

L'ANOVA (Analyse de Variance) permet de comparer plusieurs groupes dans une même analyse globale.

3. H₀ et H₁ pour comparer plusieurs groupes

Comme nous l'avons vu dans le module 7, tout test d'hypothèse oppose deux visions du monde :

$H_0$ Hypothèse nulle

« Les moyennes des groupes sont égales. »

$$H_0 : \mu_A = \mu_B = \mu_C$$
Toutes les variétés ont le même potentiel moyen de rendement au champ.
$H_1$ Hypothèse alternative

« Au moins une moyenne est différente. »

$$H_1 : \text{Au moins une moyenne } \mu_i \text{ diffère}$$
Attention : Cela ne signifie pas que toutes les variétés sont différentes les unes des autres ! Il suffit qu'une seule variété se démarque.

4. Réaliser l'ANOVA en pratique

Sous R, l'analyse de variance à un facteur s'ajuste simplement avec la fonction aov() : 

# Ajustement du modèle d'ANOVA à 1 facteur
modele <- aov(rendement ~ variete, data = donnees)

# Affichage du tableau d'analyse de variance
summary(modele)

Le résultat produit par R fournit notamment une p-value (notée Pr(>F) dans le tableau), qui synthétise si les différences observées entre les groupes sont compatibles ou non avec le simple hasard.

5. Interpréter la p-value

Prenons un exemple concret de sortie statistique :

Exemple de résultat d'ANOVA

Le test d'ANOVA fournit une $p$-value $= 0{,}018$ avec un seuil de risque usuel $\alpha = 0{,}05$.

$$0{,}018 < 0{,}05 \implies \text{Rejet de } H_0$$

Conclusion : « Il existe une différence statistiquement significative entre au moins deux des variétés. »

Piège d'interprétation fréquent

Ne concluez pas directement : « Les trois variétés sont toutes différentes entre elles. »
Une ANOVA significative indique qu'il existe au moins une différence dans l'ensemble, mais elle ne dit pas encore précisément entre quels groupes cette différence se situe.

6. Que faire après une ANOVA significative ?

Lorsque l'ANOVA globale est significative ($p < 0{,}05$), une seconde étape commence :

L'étape des comparaisons post-hoc

Si l'ANOVA indique qu'il existe une différence, nous devons ensuite chercher entre quels groupes cette différence se trouve.

Pour cela, on utilise un test post-hoc (comme le test de Tukey HSD), qui compare les groupes deux à deux tout en contrôlant rigoureusement le risque d'erreur globale : 

# Comparaisons multiples deux à deux après l'ANOVA
TukeyHSD(modele)

Le test de Tukey permet de comparer les groupes deux à deux (A vs B, A vs C, B vs C) après l'ANOVA, afin d'identifier avec précision quelles variétés se démarquent.

7. Si l'ANOVA n'est pas significative

Considérons maintenant une autre situation expérimentale où l'ANOVA donne :

Exemple d'ANOVA non significative

Le test d'ANOVA fournit une p-value = 0,42 avec un seuil usuel α = 0,05.

0,42 > 0,05  →  On ne rejette pas H₀

Conclusion : « Les données ne fournissent pas suffisamment d'éléments pour conclure à une différence statistiquement significative entre les moyennes des groupes. »

Remarque de rigueur : On ne dit pas que les trois groupes sont forcément strictement identiques, mais simplement que les données observées sont compatibles avec le hasard d'échantillonnage.

8. Et si les conditions de l'ANOVA ne sont pas adaptées ?

L'ANOVA classique repose sur certaines conditions statistiques (notamment la distribution normale des résidus et l'égalité des variances entre les groupes).

Le recours aux méthodes non paramétriques

L'ANOVA repose sur certaines conditions. Lorsque ces conditions ne sont pas suffisamment respectées, il existe des méthodes non paramétriques. Pour comparer 3 groupes ou plus, l'alternative principale est le test de Kruskal-Wallis. 

# Test non paramétrique de Kruskal-Wallis (3 groupes ou plus)
kruskal.test(rendement ~ variete, data = donnees)

Ramses propose également ces alternatives lorsque la situation le nécessite.

9. Visualiser vos groupes

Avant et après toute analyse de variance, la visualisation graphique reste indispensable. Le graphique de référence pour comparer la dispersion de plusieurs groupes est la boîte à moustaches (Boxplot) : 

# Tracé d'un boxplot pour comparer visuellement les groupes
boxplot(
  rendement ~ variete,
  data = donnees,
  main = "Rendement selon la variété",
  xlab = "Variété",
  ylab = "Rendement"
)

10. Et dans Ramses ?

Dans l'interface de Ramses, la comparaison de 3 groupes ou plus et l'ANOVA à un facteur sont directement accessibles sans rédiger de code :

Accès direct dans l'interface de Ramses
1
Emplacement : Rendez-vous dans le menu supérieur « Tests Statistiques » puis sélectionnez « Comparaison de 3+ Groupes ».
2
Configuration :
  • Sélectionnez « ANOVA à 1 facteur (aov) + Tukey HSD Post-hoc » dans la liste déroulante « Test à effectuer : ».
  • Indiquez votre variable quantitative (ex : rendement) et votre variable de groupe (ex : variete).
  • Cochez l'option « Calculer les tests Post-Hoc (Tukey HSD) » si vous souhaitez comparer les groupes deux à deux.
  • Si les conditions ne sont pas réunies, vous pouvez sélectionner l'alternative « Test de Kruskal-Wallis (non-paramétrique) ».
3
Exécution & Résultats : Cliquez sur « Exécuter & Journaliser ». Ramses affiche instantanément :
  • La p-value globale, la statistique F et la taille d'effet ($\eta^2$) dans les tuiles d'indicateurs clés ;
  • Le résultat global et la synthèse pédagogique claire (rejet ou conservation de H₀) ;
  • Le tableau détaillé des comparaisons post-hoc (Tukey HSD) pour examiner les écarts groupe par groupe ;
  • Le code R reproductible complet dans le journal de bord.
Le rôle de l'analyste

Ramses automatise les calculs, mais vous devez toujours savoir quelle question vous posez et comment interpréter le résultat.

12. À retenir

Les points clés du chapitre
  • 2 groupes → comparaison adaptée à la structure des groupes (test t ou Wilcoxon).
  • 3 groupes ou plus → penser notamment à l'ANOVA pour éviter de multiplier les tests.
  • ANOVA significative ($p < 0{,}05$) → il existe une différence entre au moins deux groupes.
  • Post-hoc (ex: Tukey) → permet de rechercher où se trouvent précisément les différences deux à deux.
  • Conditions non adaptées → il existe des alternatives non paramétriques, comme le test de Kruskal-Wallis.
« Le nombre de groupes est l'un des premiers éléments à prendre en compte pour choisir une analyse statistique. »
