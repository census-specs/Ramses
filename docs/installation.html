Guide d'Installation de Ramses

Prérequis système, méthodes d'installation recommandées et diagnostic des dépendances.

1. Prérequis Système

Avant de procéder à l'installation de Ramses, assurez-vous que votre poste de travail dispose d'un environnement R à jour :

  • R version 4.1.0 ou supérieure : Téléchargeable gratuitement sur le site officiel du CRAN.
  • RStudio Desktop (fortement recommandé) : L'environnement de développement intégré recommandé pour exploiter le visualiseur interne et la compilation R Markdown.
  • Outils de compilation (selon votre système d'exploitation) :
    • Windows : Installez Rtools correspondant à votre version de R pour la compilation de packages C++.
    • macOS : Assurez-vous d'avoir installé les outils en ligne de commande Xcode (xcode-select --install dans le Terminal).
    • Linux (Ubuntu/Debian) : Installez les bibliothèques système libcurl4-openssl-dev, libssl-dev et libxml2-dev.

2. Méthode Recommandée : Installation via GitHub

Le package Ramses est hébergé sur GitHub. La méthode la plus simple et directe pour obtenir la dernière version stable consiste à utiliser le gestionnaire de packages légers remotes :

Console R 
# Étape A : Vérification et installation de remotes
if (!requireNamespace("remotes", quietly = TRUE)) {
  install.packages("remotes", repos = "https://cloud.r-project.org")
}

# Étape B : Installation de Ramses avec résolution automatique des dépendances
remotes::install_github(
  repo = "astral-r/Ramses",
  dependencies = TRUE,
  upgrade = "ask"
)

Le paramètre dependencies = TRUE garantit que l'ensemble des bibliothèques requises (shiny, bslib, DT, plotly, rmarkdown, haven, etc.) seront automatiquement téléchargées et installées dans votre bibliothèque R.

3. Installation Locale depuis les Sources ou Archive .tar.gz

Si vous travaillez dans un environnement hors-ligne ou sécurisé (intranet hospitalier, serveur d'entreprise sans accès internet direct) :

Option A : Depuis une archive binaire ou source (.tar.gz)

Console R 
# Spécifiez le chemin absolu vers l'archive téléchargée
install.packages(
  pkgs = "chemin/vers/Ramses_0.1.0.tar.gz",
  repos = NULL,
  type = "source"
)

Option B : Depuis le dépôt cloné localement

Si vous avez cloné le dépôt source avec Git, vous pouvez compiler et auditer le package directement avec le script d'assemblage fourni dans le dossier dev/ :

Console R 
# Depuis le répertoire racine du projet Ramses cloné
source("dev/build_package.R")

4. Résolution des Problèmes Fréquents (FAQ Technique)

1. Erreur de compilation R Markdown : "Pandoc is not available"

Ramses utilise rmarkdown et knitr pour compiler les rapports HTML. Pandoc est inclus par défaut dans RStudio. Si vous exécutez R en dehors de RStudio (ex: terminal ou serveur distant), vérifiez la disponibilité de Pandoc :

Test R 
rmarkdown::find_pandoc()
# Si indisponible, sous Ubuntu/Debian : sudo apt-get install pandoc
# Sous macOS : brew install pandoc
2. Erreur lors de l'installation des dépendances binaires (haven, plotly)

Si l'installation échoue avec un message réclamant des outils de compilation, vous pouvez forcer l'utilisation des versions pré-compilées (binaires) plutôt que de compiler depuis les sources :

Console R 
# Forcer l'installation binaire des dépendances clés
install.packages(c("haven", "readxl", "plotly", "bslib", "DT"), type = "binary")
remotes::install_github("astral-r/Ramses", upgrade = "never")
3. Port réseau occupé ou exécution sur serveur

Si le port assigné par défaut est déjà utilisé par un autre service local, vous pouvez spécifier manuellement un port alternatif : run_app(port = 4567).

5. Vérification de la Bonne Installation

Pour valider que Ramses est opérationnel dans votre environnement, lancez simplement la fonction de test :

Console R 
library(Ramses)
packageVersion("Ramses")
# Doit renvoyer : [1] '0.1.0'

# Lancement de l'application
run_app()

Une fois le serveur démarré, vous pouvez passer à l'étape suivante : découvrir le Tutoriel pas à pas.
