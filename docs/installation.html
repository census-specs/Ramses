Installer Ramses

Si vous êtes débutant en R, suivez simplement les étapes dans l'ordre. Vous n'avez pas besoin de connaître Git pour utiliser Ramses.

1. Ce qu'il vous faut

  • R 4.1.0 ou une version plus récente.
  • RStudio est fortement conseillé pour débuter, même si Ramses peut fonctionner avec R seul.
  • Une connexion Internet est nécessaire pendant l'installation de Ramses et de ses dépendances.
Pas besoin d'installer tous les packages à la main

L'installation depuis GitHub demande à R d'installer les dépendances nécessaires. Cela peut prendre quelques minutes la première fois.

2. Installer Ramses depuis GitHub

Ouvrez RStudio, puis copiez ce code dans la console R :

Console R
if (!requireNamespace("remotes", quietly = TRUE)) {
  install.packages("remotes")
}

remotes::install_github(
  "census-specs/Ramses",
  dependencies = TRUE,
  upgrade = "ask"
)

Si R vous demande si vous voulez mettre à jour certains packages, vous pouvez généralement choisir l'option proposée par défaut.

3. Lancer Ramses

Une fois l'installation terminée :

Console R
library(Ramses)
run_app()

Ramses ouvre normalement une fenêtre d'application avec votre navigateur compatible. Si aucun navigateur compatible avec le mode « fenêtre dédiée » n'est trouvé, l'application utilise le navigateur standard.

4. Premier démarrage : que vais-je voir ?

Ramses démarre avec le jeu de données iris. C'est volontaire : vous pouvez tester l'application immédiatement sans préparer un fichier.

  1. Regardez le tableau de données.
  2. Ouvrez Préparation pour voir le diagnostic.
  3. Ouvrez Statistiques descriptives pour calculer quelques indicateurs.
  4. Essayez Visualisation pour créer un graphique.
  5. Essayez ensuite un test dans Tests statistiques.

5. Installer depuis une copie locale du package

Cette méthode est surtout utile si vous développez Ramses ou si vous avez téléchargé/cloné le dépôt.

Dans RStudio, ouvrez le projet Ramses puis utilisez :

R
remotes::install_local("chemin/vers/Ramses")

Depuis la racine du dépôt, le script dev/build_package.R peut également servir aux opérations de développement et de construction du package.

7. Si l'installation échoue

Erreur : « package ... is not available »

Commencez par vérifier votre version de R :

R
R.version.string

Si R est ancien, mettez-le à jour puis relancez l'installation de Ramses.

Erreur concernant un package dépendant

Essayez d'abord d'installer le package indiqué par le message :

Exemple
install.packages("nom_du_package")
remotes::install_github("census-specs/Ramses", dependencies = TRUE)

Ramses ne s'ouvre pas

Vous pouvez lancer l'application sans ouverture automatique du navigateur :

R
library(Ramses)
run_app(launch.browser = FALSE)

Vous pouvez aussi choisir un port précis :

R
run_app(port = 3838)

8. Vérifier que Ramses est bien installé

Dans R :

R
packageVersion("Ramses")
Ramses::run_app()

La version attendue actuellement est 1.0.0.
