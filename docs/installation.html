Installer Ramses

Installation locale, lancement et dépannage de la version 0.1.0.

1. Prérequis

  • R ≥ 4.1.0.
  • Une connexion Internet est nécessaire pour l'installation depuis GitHub.
  • RStudio est recommandé, mais Ramses peut également être lancé depuis une session R classique.
  • Les outils de compilation ne sont pas nécessaires au package lui-même, mais peuvent être demandés par R si une dépendance doit être installée depuis les sources.

2. Installation depuis GitHub

Le dépôt officiel de développement est census-specs/Ramses.

R
if (!requireNamespace("remotes", quietly = TRUE)) {
  install.packages("remotes")
}

remotes::install_github("census-specs/Ramses")

3. Installation locale

Après avoir cloné ou téléchargé le dépôt :

R
install.packages("devtools")
devtools::install("chemin/vers/Ramses")

Le script dev/build_package.R peut aussi être utilisé pendant le développement. Il documente, vérifie et installe le package, mais il dépend lui-même de rprojroot, devtools, roxygen2, rmarkdown, knitr et testthat.

4. Lancer l'application

R
library(Ramses)
run_app()

run_app() construit un objet Shiny. Dans une session R interactive, son impression lance l'application ; ce comportement est celui documenté par Shiny pour les objets créés avec shinyApp(). Documentation Shiny

5. Modes de lancement

R
# Navigateur standard
run_app(standalone = FALSE)

# Port précis
run_app(port = 3838)

# Serveur / conteneur
run_app(host = "0.0.0.0", port = 3000, launch.browser = FALSE)

Le mode standalone = TRUE cherche Chrome, Chromium, Edge ou Brave afin d'ouvrir une fenêtre de type application. Si aucun navigateur compatible n'est trouvé, le navigateur système est utilisé.

7. Dépannage

Rapport HTML impossible à compiler

Le rapport utilise rmarkdown::render() et donc un environnement capable de fournir Pandoc. Vérifiez rmarkdown::find_pandoc().

Dépendances

Si une dépendance échoue à l'installation, installez-la séparément depuis CRAN puis relancez l'installation de Ramses.

Port occupé

Utilisez par exemple run_app(port = 4567) ou laissez Ramses choisir un port libre.

8. Vérification

R
library(Ramses)
packageVersion("Ramses")
run_app()

La version actuelle du dépôt est 0.1.0.
