Ramses

Interface Graphique Moderne d'Analyse Statistique et de Reproductibilité en R

version 0.1.0 R >= 4.1.0 Licence MIT R Markdown / knitr Bootstrap 5 (bslib)

Pourquoi Ramses ?

Depuis plus de deux décennies, R Commander (Rcmdr) a joué un rôle pionnier dans l'enseignement et la pratique des biostatistiques appliquées en démocratisant l'accès à R via une interface graphique. Cependant, les contraintes ergonomiques des fenêtres graphiques X11/Tcl/Tk et l'absence d'intégration native aux standards modernes du web imposaient une modernisation en profondeur.

Ramses a été développé pour combler cette lacune en proposant une interface web réactive, contemporaine et accessible construite avec Shiny et bslib (Bootstrap 5). Conçu pour les chercheurs, data analysts, biostatisticiens, enseignants et étudiants, Ramses privilégie l'intégrité scientifique : toutes les manipulations et calculs effectués à l'écran sont rigoureusement traduits en code R pur et consignés dans un journal R Markdown reproductible.

Les 4 Piliers de l'Architecture Ramses

1. Menus Modaux & Navigation Fluide

Exploration tabulaire interactive avec DT::datatable, importation guidée multi-formats (CSV, Excel, SPSS, Stata, RDS) et paramétrage modulaire sans rechargement de page.

2. Analyses Statistiques Complètes

Statistiques descriptives univariées et bivariées, tests paramétriques (Student, ANOVA), non-paramétriques (Wilcoxon, Kruskal-Wallis), tests du Chi-2/Fisher et régressions (OLS, logistique avec Odds Ratios).

3. Visualisation "Tableau-Style"

Générateur visuel de graphiques permettant de mapper intuitivement les variables sur les axes, couleurs, tailles et facettes. Rendu dynamique synchronisé entre ggplot2 et plotly.

4. Reproductibilité R Markdown

Journalisation chronologique temps réel de chaque analyse. Possibilité d'annoter le script et d'exporter en script R source (.R), document knitr (.Rmd) ou rapport compilé (.html).

Démarrage Rapide

Ramses s'installe et s'exécute directement depuis votre console R ou RStudio avec une seule instruction :

Console R 
# 1. Installation depuis GitHub (via le package remotes)
if (!requireNamespace("remotes", quietly = TRUE)) {
  install.packages("remotes")
}
remotes::install_github("astral-r/Ramses")

# 2. Chargement de la bibliothèque
library(Ramses)

# 3. Lancement de l'interface graphique interactive
run_app()
Mode interactif vs Serveur

Par défaut, run_app() initialise un port TCP libre et ouvre automatiquement votre navigateur système par défaut. Pour un environnement conteneurisé (Docker, Cloud Run), spécifiez run_app(host = "0.0.0.0", port = 3000, launch.browser = FALSE).
