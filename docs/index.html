Ramses

Faire des analyses statistiques avec R, sans devoir commencer par écrire du code.

Ramses est une interface graphique interactive pour préparer des données, faire des statistiques, créer des graphiques et produire un rapport reproductible.

Ramses 1.0.0 R ≥ 4.1.0 Licence MIT Shiny + bslib R Markdown

Ramses en une phrase

L'idée est simple

Vous chargez vos données → vous les vérifiez → vous les préparez → vous choisissez une analyse → Ramses affiche les résultats → le code R correspondant est conservé dans le journal.

Vous n'avez donc pas besoin de connaître R pour commencer. En revanche, Ramses ne remplace pas le raisonnement statistique : il vous aide à l'appliquer et à garder une trace de ce que vous avez fait.

Que peut faire Ramses ?

1. Importer les données

Importez des fichiers CSV, TXT/TSV, Excel (.xlsx/.xls), SPSS (.sav), Stata (.dta) ou des objets R .rds. Pour Excel, vous pouvez choisir la feuille à importer.

2. Préparer les données

Inspectez les lignes, colonnes, valeurs manquantes, doublons et valeurs aberrantes. Renommez, supprimez, réorganisez ou convertissez des variables, recodez des modalités, remplacez des valeurs et créez des variables calculées.

3. Nettoyer et filtrer

Traitez les valeurs manquantes, supprimez les doublons, nettoyez les espaces, modifiez la casse du texte, filtrez les observations, triez les lignes et sélectionnez les colonnes utiles.

4. Décrire les données

Calculez des effectifs, moyennes, médianes, variances, écarts-types, CV, minimum, maximum, IQR, asymétrie et aplatissement. Travaillez aussi par groupe.

5. Faire des tableaux

Créez des distributions qualitatives et des tableaux croisés avec effectifs, pourcentages par ligne, par colonne ou sur le total.

6. Étudier les relations

Calculez des corrélations Pearson ou Spearman dans les descriptifs, puis Pearson, Spearman ou Kendall dans les tests de corrélation.

7. Tester des hypothèses

Normalité, égalité des variances, tests t, Wilcoxon, ANOVA, Kruskal-Wallis, Chi-deux, Fisher, McNemar et tests de proportions sont disponibles.

8. Modéliser

Ajustez une régression linéaire simple ou multiple, ou une régression logistique binaire, avec tableaux de résultats et diagnostics.

9. Visualiser

Construisez des graphiques interactifs : nuage de points, barres, camembert, boxplot, violon, histogramme, ligne, densité et heatmap.

10. Garder le code

Les opérations réalisées dans l'interface peuvent être ajoutées au Journal R Markdown, puis exportées en .R, .Rmd ou .html.

Quel test choisir ?

Pour un débutant, commencez par la question, pas par le nom du test.

Votre questionOutil Ramses à regarder
Mes données suivent-elles approximativement une loi normale ?Normalité & Variance
Une moyenne est-elle différente d'une valeur donnée ?Test t — échantillon unique
Deux groupes ont-ils des moyennes différentes ?Test t indépendant / Welch
Les mesures avant et après sont-elles différentes ?Test t apparié ou Wilcoxon apparié
Trois groupes ou plus ont-ils des moyennes différentes ?ANOVA ou Kruskal-Wallis
Deux variables qualitatives sont-elles associées ?Chi-deux ou Fisher
Deux proportions sont-elles différentes ?Tests de proportions
Deux variables quantitatives sont-elles liées ?Corrélation Pearson / Spearman / Kendall
Je veux expliquer une variable quantitative.Régression linéaire
Je veux expliquer une variable binaire.Régression logistique
Important

Un test statistique ne se choisit pas uniquement avec un menu. Il faut tenir compte du type de variable, du plan d'étude, de l'indépendance ou de l'appariement des observations, des hypothèses du test et du contexte scientifique.

Pourquoi le journal R Markdown est important ?

Ramses ne se limite pas à afficher un résultat. Lorsque vous réalisez une opération analytique, l'application peut conserver le code R correspondant dans le journal.

À la fin, vous pouvez produire :

  • .R : le code R exécutable ;
  • .Rmd : le document source R Markdown ;
  • .html : un rapport HTML compilé.

Commencer en 3 étapes

  1. Installer Ramses depuis la page Installation.
  2. Charger un jeu de données. Si vous débutez, Ramses démarre avec le jeu de données iris.
  3. Suivre le parcours : préparer → décrire → visualiser → tester → documenter.

library(Ramses)

Ce que Ramses ne fait pas à votre place

Ramses automatise l'exécution et la présentation de nombreuses méthodes. Il ne décide pas si votre étude est bien conçue, si vos variables mesurent réellement ce que vous voulez mesurer ou si une conclusion est scientifiquement pertinente.

Le bon réflexe : utiliser Ramses pour faciliter l'analyse, puis expliquer clairement pourquoi la méthode choisie répond à votre question.
