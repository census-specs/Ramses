Tutoriel Ramses pour débuter

Ce tutoriel vous montre une démarche complète. Prenez votre temps : le but n'est pas de cliquer partout, mais de comprendre ce que vous faites.

Le parcours conseillé

La règle des 5 étapes

1. Préparer → 2. Décrire → 3. Visualiser → 4. Tester/Modéliser → 5. Documenter.

Ce parcours est valable pour une grande partie des analyses de données. Ramses vous donne les outils ; à vous de relier chaque étape à votre question scientifique ou professionnelle.

Étape 1 — Ouvrir Ramses

R
library(Ramses)
run_app()

Ramses démarre avec le jeu de données iris. Vous pouvez donc vous entraîner immédiatement.

Étape 2 — Comprendre votre jeu de données

Avant de faire un test, demandez-vous :

  • Combien ai-je d'observations ?
  • Combien ai-je de variables ?
  • Quelles variables sont quantitatives ?
  • Quelles variables sont qualitatives ?
  • Y a-t-il des valeurs manquantes ?
  • Y a-t-il des doublons ou des valeurs suspectes ?

Dans Préparation des données → Explorer, Ramses affiche notamment les dimensions du jeu, les valeurs manquantes, les doublons, les valeurs aberrantes et le type des variables.

Étape 3 — Importer vos propres données

Ouvrez la commande d'importation et choisissez votre fichier.

FichierCe que vous pouvez régler
CSV / TXT / TSVSéparateur, décimales et présence d'un en-tête.
ExcelFeuille à importer et noms de colonnes.
SPSSConversion des variables labellisées en facteurs.
StataConversion des variables labellisées en facteurs.
RDSLecture directe de l'objet R.

Après le chargement, Ramses remplace le jeu actif et ajoute l'opération d'importation au journal.

Étape 4 — Nettoyer les données

Dans Préparation des données, vous disposez de plusieurs familles d'opérations.

Modifier les variables

  • renommer une variable ;
  • supprimer des variables ;
  • réorganiser les colonnes ;
  • changer le type d'une variable ;
  • recoder des modalités ;
  • remplacer une valeur ;
  • créer une variable calculée.

Nettoyer

  • supprimer les lignes contenant des NA ;
  • remplacer les NA par une valeur ;
  • imputer par moyenne, médiane ou mode ;
  • supprimer les doublons ;
  • nettoyer les espaces et la casse du texte.

Filtrer et trier

Vous pouvez filtrer les observations, trier les lignes ou sélectionner uniquement certaines variables.

Attention aux transformations

Ne supprimez pas ou n'imputez pas une valeur uniquement parce qu'elle vous gêne. Une donnée inhabituelle peut être une vraie observation. Il faut comprendre sa cause avant de la modifier.

Étape 5 — Faire une analyse descriptive

Variable quantitative

Vous pouvez demander notamment : N, NA, moyenne, médiane, variance, écart-type, CV, minimum, maximum, IQR, asymétrie et aplatissement.

Vous pouvez également analyser une variable par groupe.

Variable qualitative

Ramses fournit les effectifs, pourcentages et pourcentages cumulés, avec diagramme en barres ou camembert.

Deux variables qualitatives

Le tableau croisé permet d'afficher les effectifs ou les pourcentages par ligne, par colonne ou sur le total.

Deux variables quantitatives

La matrice de corrélation peut utiliser Pearson ou Spearman et afficher les p-values.

Étape 6 — Construire un graphique

Ouvrez Visualisation. Choisissez d'abord le type de graphique, puis associez vos variables aux dimensions.

FacetteFaut-il créer un petit graphique par groupe ?

Le générateur propose notamment nuage de points, barres, camembert, boxplot, violon, histogramme, ligne, densité et heatmap.

Vérifiez toujours le type des variables, le nombre de groupes, l'indépendance ou l'appariement et les hypothèses du test.

Étape 8 — Comprendre la normalité et les variances

Ramses propose Shapiro-Wilk, Shapiro-Wilk par groupe, Kolmogorov-Smirnov, Bartlett et Fligner-Killeen.

Un résultat de normalité avec une p-value élevée ne signifie pas « les données sont parfaitement normales ». Cela signifie simplement que le test n'a pas détecté d'écart statistiquement significatif à la normalité au seuil choisi.

Pour une comparaison de deux groupes, Ramses permet notamment de choisir entre l'hypothèse de variances égales et l'approche de Welch.

Étape 9 — Comparer les groupes

Dans Comparaison de 2 groupes, vous pouvez choisir :

  • échantillon unique ;
  • deux groupes indépendants ;
  • échantillons appariés ;
  • Wilcoxon à 1 échantillon ;
  • Mann-Whitney indépendant ;
  • Wilcoxon apparié.

Vous pouvez également choisir une hypothèse bilatérale ou unilatérale et un seuil alpha de 1 %, 5 % ou 10 %.

Étape 10 — Trois groupes ou plus

Utilisez ANOVA si votre cadre statistique le justifie, ou Kruskal-Wallis comme approche non paramétrique.

Ramses peut calculer des comparaisons post-hoc : Tukey HSD pour l'ANOVA et une procédure de Dunn pour Kruskal-Wallis lorsque l'option correspondante est activée.

Étape 11 — Variables qualitatives et proportions

Pour deux variables qualitatives, Ramses propose le Chi-deux, Fisher et McNemar pour des données appariées.

Pour les proportions, vous pouvez tester une proportion contre une valeur de référence ou comparer deux proportions. Les tests peuvent être bilatéraux ou unilatéraux.

Étape 12 — Corrélation et régression

Corrélation

Vous pouvez tester Pearson, Spearman ou Kendall, avec une hypothèse bilatérale ou unilatérale.

Régression linéaire

Utilisez-la lorsque la variable à expliquer est quantitative. Ramses accepte plusieurs variables explicatives.

Régression logistique binaire

Utilisez-la lorsque la variable à expliquer est binaire, par exemple oui/non. Les résultats comprennent notamment les coefficients et les indicateurs liés au modèle.

Une régression demande plus qu'un clic

Il faut réfléchir au sens des variables, au codage, aux hypothèses du modèle et à l'interprétation des coefficients. Le diagnostic des résidus disponible dans Ramses aide à contrôler le modèle.

Étape 13 — Lire le résultat

Ne regardez pas uniquement la p-value. Selon l'analyse, regardez aussi :

  • la statistique du test ;
  • la p-value ;
  • l'estimation ou la différence observée ;
  • l'intervalle de confiance lorsqu'il est fourni ;
  • la taille d'effet lorsqu'elle est calculée ;
  • le contexte et l'importance pratique du résultat.

Une différence peut être statistiquement significative sans être importante en pratique. L'inverse peut également arriver avec un petit échantillon.

Étape 14 — Garder une trace de l'analyse

Chaque fois qu'une analyse ou une transformation est journalisée, elle apparaît dans Journal Rmd. Vous pouvez :

  • ajouter une note personnelle ;
  • copier le script ;
  • réinitialiser le journal ;
  • exporter un script .R ;
  • exporter le document .Rmd ;
  • générer un rapport .html.

Un exemple complet de démarche

Supposons que vous voulez savoir si le rendement agricole moyen est différent avant et après une intervention.

  1. Importer les données.
  2. Vérifier les variables et les valeurs manquantes.
  3. Identifier les deux mesures comme appariées si elles concernent les mêmes exploitations avant et après.
  4. Examiner la distribution des données ou, selon le cadre, des différences avant/après.
  5. Utiliser le test t apparié si les conditions sont raisonnables, ou envisager Wilcoxon si l'approche non paramétrique est appropriée.
  6. Regarder la différence, la p-value et l'importance pratique.
  7. Conserver le code et le rapport dans le Journal Rmd.

Cette logique est plus importante que le nom du bouton : la méthode vient de la question et du plan de l'étude.

Checklist avant de présenter vos résultats

  • ☐ Les données ont été vérifiées.
  • ☐ Les valeurs manquantes ont été examinées.
  • ☐ Les variables sont correctement codées.
  • ☐ Le test correspond au plan d'étude.
  • ☐ Les hypothèses importantes ont été vérifiées.
  • ☐ Le résultat statistique est correctement interprété.
  • ☐ L'importance pratique a été discutée.
  • ☐ Le code ou le rapport a été conservé.
