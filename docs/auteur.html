À propos de Ramses

Comprendre le projet, son objectif et la personne qui le développe.

Pierre Valdeze MBOM MBOM

Auteur et développeur principal de Ramses

Le projet est développé comme un outil R ouvert destiné à faciliter l'apprentissage et la pratique de l'analyse statistique.

Contact : association.astral@gmail.com

Pourquoi Ramses existe ?

R utilise un langage puissant pour l'analyse statistique, mais apprendre le code peut être un obstacle pour une personne qui veut surtout comprendre ses données.

Ramses cherche à réduire cet obstacle avec une interface graphique : on choisit une variable, une opération ou une méthode, puis l'application réalise le calcul et présente le résultat.

Le projet ajoute un deuxième objectif essentiel : ne pas enfermer l'utilisateur dans une interface graphique. Les analyses peuvent être journalisées sous forme de code R et de R Markdown afin de faciliter la vérification, la reproduction et l'apprentissage.

La philosophie du projet

Simple à utiliser

Les menus doivent être compréhensibles par une personne qui débute en analyse de données.

Statistiquement sérieux

Les outils proposés reposent sur les méthodes statistiques disponibles dans l'écosystème R.

Reproductible

Les opérations importantes peuvent être conservées sous forme de code R et de rapport R Markdown.

Ouvert

Le code source est disponible sur GitHub et peut être inspecté, testé et amélioré par la communauté.

Ce que contient Ramses 1.0.0

  • Importation de données : CSV/TXT/TSV, Excel, SPSS, Stata et RDS.
  • Préparation des données : diagnostic, nettoyage, recodage, remplacement, calcul de variables, filtrage et tri.
  • Statistiques descriptives quantitatives et qualitatives.
  • Tableaux croisés et pourcentages.
  • Corrélations descriptives.
  • Tests de normalité et d'homogénéité des variances.
  • Tests t et Wilcoxon.
  • ANOVA, Kruskal-Wallis et comparaisons post-hoc.
  • Chi-deux, Fisher et McNemar.
  • Tests de proportions.
  • Corrélations Pearson, Spearman et Kendall.
  • Régressions linéaires et logistiques.
  • Créateur de graphiques interactifs.
  • Journal R Markdown et export R, Rmd et HTML.

Un projet destiné aussi à l'apprentissage

Ramses peut être utilisé par des étudiants, enseignants, chercheurs, analystes de données ou professionnels qui veulent obtenir rapidement une première analyse tout en gardant la possibilité de voir le code R produit.

Cette approche permet une progression naturelle :

  1. commencer avec l'interface graphique ;
  2. observer le code R généré ;
  3. comprendre progressivement les fonctions utilisées ;
  4. passer ensuite à une analyse entièrement scriptée lorsque cela devient utile.
